UPLOAD WITH FILEZILLA (FTP)
  1. FileZilla > File > Site Manager > New site.
  2. Host / Username / Password / Port: copy them from your hosting account.
  3. Connect. On the server side open the web root folder (public_html, htdocs or www).
  4. Drag everything INSIDE this folder (index.html, products.html, contact.html,
     css, js, images) into the web root. index.html must sit directly in it.
  5. Visit your domain and refresh (Ctrl+F5).
